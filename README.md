# Very Good Studio — Coming Soon

Static coming soon page for [very-good-studio.com](https://very-good-studio.com), deployed via [Railway](https://railway.app).

## Deploy

This site is configured for Railway's static hosting via Nginx.

1. Push to `main`
2. Railway auto-deploys on every push
3. Set your custom domain (`very-good-studio.com`) in Railway project settings → **Custom Domain**

## Local preview

Open `index.html` directly in a browser — no build step required.
